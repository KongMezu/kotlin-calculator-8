# kotlin-calculator-precourse
## ✨구현 기능 목록
### ➕ 기본 덧셈 기능
1. 빈 문자열 입력 시, 0 반환 
```
입력 : ""
출력 : 0
```

2. 숫자 1개 주어지면 그대로 숫자 값 반환
```
입력 : "2"
출력 : 2
```

3. 쉼표, 콜론(기본 구분자들) 는 구분자로 사용, 숫자 분리 후 합 반환
```
입력 : "1,2:3"
출력 : 6
```
### 🔧커스텀 구분자 기능
1. 문자열 앞에 사용자는 커스텀 구분자를 지정할 수 있도록 한다.
2. 구분자 지정은  `//'구분자'\n` 으로 //과 \n 에 넣어 설정할 수 있도록 한다.
```
입력 : "//;\n1;2;3" #이 경우 구분자는 ; 이다.
출력 : 6
```
### 🚨예외 처리
1. 숫자 아닌 값, 음수, 기본 구분자 외 지정하지 않은 구분자 등이 올 경우
 `IllegalArgumentException` 발생 시키고 종료 되도록 한다.
2. 모든 계산 식은, 1번 하고 종료하도록 한다.
